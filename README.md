# На Уровне MSK — концепция сайта

Статическая первая версия сайта строительной компании: архитектурный минимализм + продающая структура для заявок на расчёт домов из СИП-панелей.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Затем откройте `http://127.0.0.1:8000/`.

Каталог и квиз работают в браузере. Отправка заявок, amoCRM и Яндекс Метрика пока не подключены — для них нужны подтверждённые реквизиты, серверный канал и идентификатор счётчика.


Тестовая публикация Cloudflare Pages отслеживает ветку `design/cozy-country-2026`; основной сайт и ветка `main` не используются.
